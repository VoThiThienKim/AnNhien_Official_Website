# Sample Dish Image Prompts

Use these prompts to generate temporary menu imagery before the restaurant provides real food photography. Keep all outputs aligned with `docs/design-style.md`.

## Global Style Prompt

Use this prefix for every dish:

```text
Modern Plant Bistro food photography for An Nhien vegan cuisine in Vietnam, fresh clean mindful plant-based warm Vietnamese aesthetic, natural daylight, warm ivory background, light wood table, subtle green herbs, bright vegetables, realistic plated restaurant dish, appetizing but calm, editorial menu photo, shallow depth of field, soft shadows, no people, no text, no logo, no watermark
```

## Negative Prompt

```text
dark moody lighting, heavy brown palette, greasy food, meat, fish, egg, dairy, plastic tableware, messy plate, religious statue, incense, spa stones, over-blurred image, extreme close-up, fake-looking garnish, text, logo, watermark, hands, people, low resolution
```

## Recommended Formats

- Menu card: `4:3`, dish centered, enough negative space for crop.
- Hero food banner: `16:9`, table scene, dish cluster on one side, calm depth.
- Social square: `1:1`, dish close enough to inspect ingredients.
- Transparent cutout: only if needed for marketing assets, not default web UI.
